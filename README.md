# Signal Dept. Storefront

A dependency-free storefront prototype built with native browser JavaScript modules.

## Project layout

```text
assets/
  css/styles.css
  downloads/demo-starter-kit.txt
src/
  data/products.js   Product catalog and product specifications
  js/main.js         Store interactions and UI rendering
index.html           Page structure and metadata
```

Open the project through a local web server or static host so the browser can load the JavaScript modules. No package install or build step is required.
